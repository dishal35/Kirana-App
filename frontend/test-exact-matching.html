Test Exact Matching with Simulated Transactions

This page is for testing the exact matching functionality. Follow these steps:

  1. Open your main app at http://localhost:5173
  2. Open Developer Console (F12)
  3. Run the following commands to test exact matching:

Test Commands


// 1. First, verify the app is set up
window.testUtils.verifySetup()

// 2. Test exact matches for known product combinations
// Test single product exact match (if you have a ₹45 product)
window.testUtils.simulateTransaction(45)

// Test multiple quantity exact match (if you have products that sum to ₹90)  
window.testUtils.simulateTransaction(90)

// Test combination match (e.g., ₹165 = ₹45 rice + ₹120 tea)
window.testUtils.simulateTransaction(165)

// Test no exact match case
window.testUtils.simulateTransaction(99)

What to Look For

  • Console Logs: Look for "🎯 Found X exact product matches" or "⚠️ No exact combinations found"
  • Transaction Modal: Should show exact product suggestions with correct quantities
  • Modal Header: Should indicate "Exact matches found" or "No exact combinations found"
  • Product Selection: Auto-selected products should have the right quantities set
